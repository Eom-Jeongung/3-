# LG Display 특허 트렌드 센싱

LG디스플레이와 경쟁사(삼성디스플레이, 중국 4사)의 한국 공개 특허를 자동으로 모아 기술 분야별로 나누고,
**어느 분야에서 출원이 늘고 있는지**를 그래프와 AI 요약으로 보여 주는 웹 서비스예요.

> **배포 주소:** https://3-production-29617a15.up.railway.app
> 접속 비밀번호는 팀에 문의해 주세요. 설치 없이 브라우저(Chrome·Edge)로 바로 쓸 수 있어요.

## 1. 무엇을 할 수 있나요

| 하고 싶은 일 | 가는 곳 |
|---|---|
| 최근 1년 동안 각 회사가 특허를 얼마나 냈는지 한눈에 보기 | **대시보드** |
| OLED 회로처럼 특정 기술 분야에서 세 회사의 출원 추이 비교하기 | **기술 분야별 분석** |
| 그 분야에서 무슨 일이 있었는지 AI가 정리한 글로 읽기 | **AI 동향 요약** |
| 최근 갑자기 많이 나오기 시작한 기술 용어 찾기 | **신기술 탐지** |
| 키워드로 특허를 찾고 초록·청구항·도면 보기 | **특허 목록** |

- 대상 회사: **LG디스플레이(자사)**, **삼성디스플레이**, **중국 4사(BOE·CSOT·Tianma·Visionox)**
- 대상 특허: 한국 특허청(KIPRIS)에 공개·등록된 특허 약 8.8만 건
- 갱신: 새 특허는 **90일마다 자동**으로 받아 와요. 따로 누를 버튼이 없어요.

## 2. 처음 접속하기

1. 배포 주소를 열면 **접속 비밀번호** 화면이 나와요. 팀에서 받은 비밀번호를 넣고 들어가요.
2. 한 번 들어가면 **7일 동안** 다시 묻지 않아요.
3. 비밀번호를 **10번 틀리면 15분 동안** 막혀요. 잠시 뒤 다시 시도하세요.
4. 처음이라면 왼쪽 메뉴 아래 **"1분 사용 안내"** 를 눌러 보세요. 화면 5개를 한 장에 설명해 줘요.

화면 구성은 **왼쪽 메뉴(화면 5개)** + **맨 위 검색창**이에요. 휴대폰에서도 열 수 있어요.

## 3. 화면별 사용법

### 대시보드

처음 열리는 화면이에요.

- **위쪽 숫자 카드:** 최근 12개월 동안 공개된 특허 수를 전체·자사·삼성·중국 4사로 나눠 보여 주고, 1년 전보다 늘었는지(↑)·줄었는지(↓) 표시해요.
- **연간 특허 출원 추이:** 최근 5년 동안 회사별로 몇 건을 출원했는지 그래프로 보여 줘요.
- **기술 분야별 출원 비중:** OLED·LCD 같은 방식별로 몇 %인지 도넛 그래프로 보여 줘요.
- **많이 늘어난 세부 기술:** 1년 전보다 출원이 크게 늘어난 기술이에요. 누르면 그 분야 화면으로 가요.
- **최근 공개 동향:** 회사마다 기술 분야별로 최근 공개 건수와 증감을 보여 줘요.

### 기술 분야별 분석

기술 분야를 **넓은 것 → 좁은 것** 순서로 골라 들어가는 화면이에요.

1. 위쪽에서 **방식**(OLED, LCD, 공통, 마이크로LED)을 고르고,
2. **기술 분야**(회로, 광학, 공정, 소자 등)를 고르고,
3. 필요하면 **세부 기술**(화소 회로, 봉지 등)까지 좁혀요.

고를 때마다 그 분야의 회사별 출원 추이 그래프와 **이 분야의 특허** 목록이 바뀌어요.
그래프 아래 **"이 분야 AI 동향 요약 →"**, **"이 분야 급증 용어 →"** 를 누르면 같은 분야로 바로 이동해요.
특허 목록은 CSV 파일로 내려받을 수 있어요.

### AI 동향 요약

분야와 기간을 고르면 AI가 그 분야의 흐름을 글로 정리해 줘요. 위쪽에서 두 종류 중 하나를 골라요.

| 종류 | 무엇을 알려 주나 | 만드는 법 |
|---|---|---|
| **건수 요약** | "어느 회사가 어느 분야에서 몇 건 늘었나" — 핵심 메시지, 핵심 흐름, 성장 분야, 경쟁사 동향, 주목 특허, 시사점, 한계 | 분기마다 자동으로 만들어져 있어요. 없는 분야·기간은 **"AI 요약 만들기"** (1~2분) |
| **기술 분석** | "어떤 기술이 무엇을 위해 어디로 가나" — 근거 특허를 읽고 시기별 기술 흐름과 경쟁사 차이를 보고서로 정리 | **"기술 분석 만들기"** 를 눌러요 (약 40초~2분) |

- 숫자(건수, %)는 모두 DB에서 계산한 값이에요. **AI는 문장만 써요.**
- 요약 위에 **검사 결과**가 함께 나와요. "주의", "확인 필요" 같은 표시가 붙은 문장은 근거 특허를 직접 확인해 주세요.
- 기술 분석에서 **"(추정)"** 이 붙은 문장은 특허 원문에 없는 목적을 AI가 일반 지식으로 짐작한 거예요.
- 기술 분석 아래 **근거 특허 표**는 처음 3건만 보여요. **"더보기"** 를 누르면 전부 펼쳐져요.
- 예전에 만든 요약은 **"보관함"** 에서 다시 볼 수 있고, **복사**하거나 **내려받기(.md)** 할 수 있어요.

### 신기술 탐지

최근 2년 특허에서 **예전보다 눈에 띄게 많이 나온 용어**를 보여 줘요. AI를 쓰지 않고 통계로 계산해요.

- **급증 기술:** 예전에도 있었지만 최근 크게 늘어난 용어 (예: 증착용 마스크 11건 → 92건)
- **초기 신호(새로 등장):** 예전엔 거의 없다가 최근 나오기 시작한 용어
- 용어를 누르면 **"이 용어가 나온 최근 특허"** 목록이 열려요.
- 위쪽에서 분야를 고르면 그 분야 안에서만 찾아요.

### 특허 목록

- **맨 위 검색창**(어느 화면에서나)이나 이 화면의 **명칭·초록 검색**에 키워드를 넣어요. 예: `탠덤`, `봉지`
- 출원인, 상태(공개·등록), 공개일, 기술 분야로 **필터**를 걸 수 있어요. **"필터 초기화"** 로 되돌려요.
- 행을 누르면 **특허 상세** 창이 열려요.

### 특허 상세 창

| 볼 수 있는 것 | 설명 |
|---|---|
| 원문 초록, 대표 도면 | 도면을 누르면 크게 보여요 |
| 대표 청구항 | 처음엔 비어 있을 수 있어요. **"청구항 불러오기"** 를 누르면 KIPRIS에서 받아 와요 |
| 분류 결과와 근거 | 이 특허를 왜 그 분야로 나눴는지(IPC 코드·키워드) 보여 줘요 |
| AI 개별 요약 | **"AI로 요약하기"** 를 누르면 이 특허 하나를 쉬운 말로 요약해요 (30초~2분) |
| 출원번호 복사 | KIPRIS에서 원문을 찾아볼 때 써요 |

## 4. 이렇게 써 보세요 (예시)

**예 1) "요즘 OLED 회로 쪽에서 삼성은 뭘 하고 있지?"**

1. **기술 분야별 분석** → OLED → 회로를 골라요.
2. 회사별 추이 그래프에서 삼성 선이 언제부터 올라갔는지 봐요.
3. **"이 분야 AI 동향 요약 →"** → 위쪽에서 **기술 분석**을 고르고 **"기술 분석 만들기"** 를 눌러요.
4. 약 40초 뒤 나오는 보고서에서 **경쟁사 비교**와 **근거 특허 표**를 읽어요.

**예 2) "최근 새로 뜨는 기술 용어가 뭐지?"**

1. **신기술 탐지**에서 **초기 신호** 목록을 봐요.
2. 관심 있는 용어를 눌러 그 말이 나온 특허를 열어 봐요.

**예 3) "탠덤 구조 특허를 찾아 청구항을 보고 싶다"**

1. 맨 위 검색창에 `탠덤`을 넣어요.
2. 목록에서 특허를 눌러 상세 창을 열고, **"청구항 불러오기"** 를 눌러요.

## 5. 화면을 읽을 때 알아 둘 것

- **그래프의 회색 음영과 점선 = 아직 공개가 덜 된 기간이에요.**
  특허는 출원하고 약 18개월 뒤에 공개돼요. 그래서 최근 1~2년 출원은 아직 다 보이지 않아요. 줄어든 게 아니에요.
- **1년 전 건수가 30건 미만이면 증감률(%)을 보여 주지 않아요.** 2건이 5건이 되면 +150%처럼 과장되기 때문이에요.
- **기술 분야 분류는 규칙으로 자동 판정해요.** 무작위 채점으로 잰 정확도는 방식(1차) 약 93%, 기술 분야(2차) 약 84%, 세부 기술(3차) 약 66%예요.
- **'IPC 추정' 표시**가 붙은 세부 기술은 명칭·초록에 단서가 없어 IPC 코드로 짐작한 거예요. 특허 목록 필터에서 빼고 볼 수 있어요.
- **중국 4사는 한국에 낸 특허만** 집계해요. 중국 본토 출원은 들어 있지 않아서 실제보다 작게 보여요.
- **같은 기술을 여러 건으로 나눠 낸 특허도 각각 1건**으로 세요. 특정 연도가 실제보다 크게 보일 수 있어요.
- **날짜 기준이 두 가지예요.** 연간 추이 그래프는 **출원일**(기술이 언제 나왔나), 대시보드 카드와 최근 공개 동향은 **공개일**(최근 무엇이 새로 보였나) 기준이에요.

## 6. 용어 풀이

| 용어 | 뜻 |
|---|---|
| 1차 · 방식 | 디스플레이 방식. OLED · LCD · 공통(방식과 무관한 기술) · 마이크로LED |
| 2차 · 기술 분야 | 회로 · 광학 · 공정 · 소자 · TFT 소자 · 설계 · 기구 · 재료 (8종) |
| 3차 · 세부 기술 | 2차를 더 나눈 50종 (예: 회로 → 화소 회로, 게이트 구동 회로) |
| IPC | 국제특허분류 코드. 특허마다 붙는 기술 분류 번호 (예: H10K = 유기 발광 소자) |
| 출원일 / 공개일 | 특허를 낸 날 / 특허청이 내용을 공개한 날 (보통 출원 18개월 뒤) |
| 급증 용어 | 최근 2년에 그 전 4년보다 통계적으로 확실히 많이 나온 용어 |
| 초기 신호 | 예전엔 0건이었다가 최근 3건 이상 나온 새 용어 |
| 근거 특허 | AI가 요약·보고서를 쓸 때 실제로 읽은 특허. 목록으로 함께 보여 줘요 |
| 주의 / (추정) | AI 문장 중 근거가 약하거나, 원문에 없는 내용을 짐작한 부분 |

## 7. 자주 묻는 질문

**Q. 새로고침 버튼이 없어요. 최신 데이터는 어떻게 받나요?**
서버가 마지막 갱신 후 90일마다 알아서 새 특허를 받아요. 마지막 갱신 시각은 왼쪽 메뉴 아래에 있어요.

**Q. AI 요약이 안 만들어지거나 오래 걸려요.**
건수 요약은 1~2분, 기술 분석은 40초~2분쯤 걸려요. 실패하면 **"다시 시도"** 를 눌러 주세요. 계속 안 되면 팀에 알려 주세요.

**Q. AI 요약의 숫자를 믿어도 되나요?**
숫자는 AI가 아니라 DB가 계산한 값이에요. AI는 그 숫자를 받아 문장만 써요. 그래도 문장은 AI가 쓰니, "주의"가 붙은 부분은 근거 특허를 확인해 주세요.

**Q. 찾는 특허가 없어요.**
대상은 6개 회사가 한국에 낸 공개·등록 특허예요. 다른 회사나 해외 특허는 들어 있지 않아요.
최근 출원은 공개 전이라 아직 안 보일 수 있어요.

**Q. 분류가 틀린 것 같아요.**
특허 상세 창의 "분류 근거"를 확인하고 출원번호와 함께 팀에 알려 주세요. 분류 규칙을 고치는 데 쓰여요.

## 8. 내 컴퓨터에서 직접 실행하기 (개발자용)

배포 주소를 쓰는 사람은 이 장을 건너뛰어도 돼요.

### 준비물

| 항목 | 필요한 것 |
|---|---|
| Node.js | 22.12 이상 (`winget install OpenJS.NodeJS.LTS`, 설치 후 `node -v`로 확인) |
| 메모리 | 평소 약 270MB, 많을 때 약 570MB |
| 디스크 | DB 약 250MB + 여유 |
| 데이터 | 팀에서 받은 `patents.db` (깃허브에는 올라가 있지 않아요) |

### 순서

```powershell
git clone https://github.com/Eom-Jeongung/3-.git
cd 3-
npm run setup
```

1. `backend/.env.example`을 복사해 `backend/.env`를 만들고 값을 넣어요. 값은 팀에서 받아요.

   ```
   KIPRIS_API_KEY=여기에_인증키
   AI_BASE_URL=https://openrouter.ai/api/v1
   AI_API_KEY=여기에_키
   AI_MODEL=anthropic/claude-haiku-5.5
   API_PORT=4000
   ```

   - 화면만 볼 거면 키 없이도 돼요. AI 요약과 청구항 불러오기만 안 돼요.
   - `=` 앞뒤에 띄어쓰기나 따옴표를 넣지 마세요.
   - 이 파일은 깃허브에 올라가지 않아요. 키를 채팅방·문서·캡처에 올리지 마세요.

2. 받은 `patents.db`를 `backend/data/`에 넣어요. 같은 폴더에 `patents.db-shm`, `patents.db-wal`이 있으면 지워요.

3. 실행해요.

   ```powershell
   npm run dev
   ```

   브라우저에서 http://localhost:5173 을 열면 돼요. `main` 브랜치가 최신 코드이고 배포 서버도 이 브랜치를 써요.

### 자주 쓰는 명령

| 명령 (저장소 루트에서) | 언제 쓰나 |
|---|---|
| `npm run dev` | 화면과 서버 켜기 |
| `npm run sync` | 새 특허를 지금 받기 (자동 갱신을 기다리지 않을 때) |
| `npm run classify --prefix backend` | 분류 기준(CSV)을 고친 뒤 전체 다시 분류. KIPRIS 안 부름 |
| `npm run auto-summary --prefix backend` | 분기 AI 동향 요약을 지금 만들기 |
| `npm run summary-quality --prefix backend -- 30` | 최근 30일 동향 요약의 검사 통과율 보기 |
| `npm run ai-usage --prefix backend` | AI를 얼마나 불렀는지 보기 |

`npm run collect --prefix backend`(전체 수집)는 KIPRIS 무료 한도(월 1,000번) 중 약 200번을 써요. 평소에는 쓰지 마세요.
